Web Development Workshop

🕐 2:00 PM - 5:00 PM 📍 Ai Lab, AB4

About This Event

Join us for an intensive hands-on workshop on modern web development. Learn HTML5, CSS3, and JavaScript best practices from industry experts. This workshop covers responsive design, accessibility, and performance optimization.

Event Information

Date & Time December 25, 2025
2:00 PM - 5:00 PM
Location Computer Lab, Building A
Capacity 50 participants
Difficulty Level Beginner to Intermediate

Event Agenda

  • 2:00 PM - Welcome & Introductions
  • 2:15 PM - HTML5 Semantic Structure
  • 3:00 PM - Modern CSS3 Techniques
  • 3:45 PM - Break
  • 4:00 PM - JavaScript Fundamentals
  • 4:45 PM - Q&A and Discussion

What to Bring

  • Laptop with text editor (VS Code recommended)
  • Modern web browser (Chrome, Firefox, or Safari)
  • Basic programming knowledge helpful but not required

Featured Speaker

Md. Sarwar Hossain Mollah

Department Head, CIS

Md. Sarwar has 10+ years of experience in web development and has mentored hundreds of students.
